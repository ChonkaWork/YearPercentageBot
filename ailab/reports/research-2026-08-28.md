## Home Assistant's HACS silently stops updating custom integrations when the author renames, moves, or archives the source repo

**Проблема:** Home Assistant users rely heavily on HACS (Home Assistant Community Store) to install and update thousands of community-built "custom integrations" for smart-home devices. The current workaround requires the user to manually notice the problem, find the integration's three-dot menu, remove the old custom-repository entry, and manually re-add the correct new GitHub URL.
