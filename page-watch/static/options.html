Page Watch

Notifications

The toolbar badge always shows how many changes you haven't looked at. Temporary problems (offline, server errors) are only reported after three failed checks in a row.

New watches

Preselected when you add a watch. Each check is one request to that page, spread out a little so sites aren't hit at the same moment. Failed checks back off (up to once a day).

Site access

Page Watch can only fetch sites you allowed when adding a watch. Access is removed automatically when you delete the last watch for a site.

    Privacy

    The only network requests Page Watch makes are to the pages you chose to watch, at the interval you picked. There is no Page Watch server, no account and no analytics.

    Pages are requested from your browser with your cookies, like a normal visit, so pages you're signed in to can be watched. Their text is stored only in this browser (the latest version plus the last 10 changes per watch) and is never turned into web content, so nothing from a watched page can run in Page Watch.
