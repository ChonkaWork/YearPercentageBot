Explain Rust ownership with a short example.

Keep it brief, please. Привіт, café!

Every value in Rust has a single owner. When the owner goes out of scope, the value is dropped.

rust
fn main() {
    let s1 = String::from("hi");
    let s2 = s1; // s1 is moved
    println!("{}", s2);
}
  1. Each value has one owner.
  2. Assignment moves ownership.
  3. Borrowing (&s) lends access without moving.

A move costs O(1)O(1)O(1): only the pointer, length and capacity are copied.
