You said:
How do I sort a list of dicts by a key in Python? Also: what's the complexity? I tried `sorted(data)` and got a *TypeError*.
ChatGPT said:

Use sorted() with a key function. Dicts can't be compared with each other, which is why sorted(data) raises TypeError.

python
from operator import itemgetter

people = [{"name": "Ada", "age": 36}, {"name": "Linus", "age": 28}]
by_age = sorted(people, key=itemgetter("age"))
by_name_desc = sorted(people, key=lambda p: p["name"], reverse=True)

Complexity

Python uses Timsort: O(nlog⁡n)O(n \log n)O(nlogn) comparisons in the worst case and O(n)O(n)O(n) on already sorted data.

T=nlog2nT(n) = \sum_{i=1}^{\log_2 n} n = n \log_2 nT(n) = n log n
